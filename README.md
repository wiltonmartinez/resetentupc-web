# ResetEnLinea-Site

Sitio público de ResetEnLinea, construido con [Astro](https://astro.build).

Especificación completa del proyecto: [RESETENLINEA-ASTRO-PROYECTO.md](RESETENLINEA-ASTRO-PROYECTO.md).

## Comandos

| Comando | Acción |
|---|---|
| `npm install` | Instala dependencias |
| `npm run dev` | Servidor de desarrollo local |
| `npm run build` | Build de producción en `dist/` |
| `npm run preview` | Sirve el build de producción localmente |

## Idiomas

Español (predeterminado, sin prefijo), inglés (`/en/`), portugués (`/pt/`), francés (`/fr/`) e italiano (`/it/`).
